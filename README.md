# Party Menu

Static party menu website for Di Bay Muon.

## Run locally

```sh
npm run dev
```

Open `http://localhost:4173`.

## Deploy

This site is static. Deploy the whole folder to Netlify, Vercel, or GitHub Pages.

### Netlify

Drag this folder into Netlify Drop, or connect the repo and use:

- Build command: none
- Publish directory: `.`

### Vercel

Import the folder/repo as a static project. No build command is required.

### GitHub Pages

Push this folder to a GitHub repository and enable Pages from the repository settings. Use the root directory as the publish source.
